# asset-inventory
a tool for soc analysts that saves your assets and the relationship between those assets locally, if you scan this with virus total it will show multiple alerts so i added the source code so you could inspect it yourself.
------------------------------------------------------------------------------------------------

## Download and run

Download asset inventory.exe and open it on Windows 10 or 11 (64-bit). No Python installation is required.

Windows may show an unknown-publisher warning because the app is not code-signed.

## Features

- Add, edit, delete, and filter device records
- Group devices by organization and manage device, connection, and user-type options
- View relationships between registered devices in the Connection Tree
- Switch between light and dark themes and adjust text size

## Data and privacy

Inventory data stays in the app’s memory until you choose a JSON file to import or export. After choosing a file, changes are saved to it automatically. If you close the app with unsaved work and no file selected, the app warns you first.

The app does not send inventory data to GitHub or make background network requests. Its GitHub link opens the profile in your browser when clicked. Exported inventory files may contain sensitive network details; keep them private.

Display preferences apply for the current session.
